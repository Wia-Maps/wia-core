# University starter kit

| File | Use |
| --- | --- |
| [config.template.json](./config.template.json) | Planning checklist for campus name, bounds, and feature flags — mirror these values in `web/src/config/client.ts` |
| [overpass_queries.txt](./overpass_queries.txt) | Overpass Turbo script (`{{bbox}}` = current map view) |
| [PITCH_DECK_OUTLINE.md](./PITCH_DECK_OUTLINE.md) | Executive slide outline for institutional buy-in |

Campus geometry itself lives in `server/public/data/` (see [server/public/data/README.md](../server/public/data/README.md)).
